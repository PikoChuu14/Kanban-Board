# FlowOps

FlowOps is a self-hosted operational workflow and task management platform designed for teams that need departmental Kanban boards, workload tracking, daily and weekly reporting, review workflows, notifications, and local Windows deployment.

## Capabilities

- Role-aware workspaces for staff, managers, and administrators
- Departmental and personal Kanban boards
- Workload, review, notification, and reporting workflows
- Local PostgreSQL-backed deployment with backup and restore tooling
- Windows installer and service operation for self-hosted environments

## Development

See [DEVELOPMENT.md](DEVELOPMENT.md) for local setup. Production and installer guidance is in [DEPLOYMENT.md](DEPLOYMENT.md) and [INSTALLER_DEPLOYMENT.md](INSTALLER_DEPLOYMENT.md).
